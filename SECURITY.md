# Security

launch-radar makes no network calls, stores no credentials and never acts on anything.
It reads text you give it and prints numbers.

If you find something that contradicts that sentence, open an issue or message
[@renaisancexbt](https://x.com/renaisancexbt) on X. Please do not post exploit details
publicly before we have had a chance to look.

## Scope

* Regex denial-of-service on crafted input: in scope.
* Anything in the planned `watch` / Telegram modules once they exist: in scope.
* The accuracy of the score: not a security issue, open a normal issue.
